# 期刊投稿选刊评估

## Overview

选刊是**五维硬约束匹配**问题，不是"名气排序"问题：**竞品拥挤度** × 稿件规格 × 期刊体例上限 × 分区/CCF口径 × 约稿与提案通道。

**核心原则一：先扫竞品，再比分区。** 目标刊近期发过几篇同题材、有没有人已经把你的核心主张说了——这件事能直接颠倒排序，却最容易被跳过。

**核心原则二：所有分区/IF/篇幅数字必须联网核实，禁止凭印象或用估计值填表。** 一次估计值错误（曾把 IF 记成区间值）足以颠倒推荐排序；官网网页版还可能滞后于最新目录。

## When to Use

- 用户问"投什么刊合适""Nature 子刊行不行"
- 需要按梯队（子刊 / 1区·CCF-A·高IF / 2区·CCF-B）罗列候选
- 已有稿件规格（词数/引用数/图表数），需判断哪些刊装得下
- 用户在"压缩篇幅冲高档刊"与"保完整版投对口刊"之间犹豫

**不适用**：期刊已选定后的写作流程 → `academic-paper-writing`

## 工作流

### Step 1：先锁定稿件规格（这是筛选的硬约束）

从用户的写作蓝图/大纲/成稿中提取三个数字：**正文字数、引用条数、图表总数**。没有这三个数字就无法做任何有意义的匹配——先问或先算，不要跳过。

⚠️ **若稿件规格来自已发表论文的 PDF（例如"某刊发过 N 词的先例"），必须剥离后再计数**：

**pypdf/PyMuPDF 提取的总词数 ≠ 期刊字数上限所指的正文词数。** 参考文献占比可达 **11%–41%**（引用越多偏差越大），另需剥离摘要、图注、表注、页眉。

实测数据（AIVC 综述选刊时踩到，直接颠倒了推荐结论）：

| 论文 | PDF 总词数 | 参考文献 | **真实正文** | 偏差 |
|---|---:|---|---:|---|
| Jiang (BriefBioinform) | 11,838 | 3,291 (27.8%) | **~7,000–8,271** | −30% |
| Ma (npj DigitMed) | 18,472 | 7,617 (41.2%) | **~10,855** | −41% |
| Bunne (Cell) | 16,124 | 4,856 (30.1%) | **~11,256** | −30% |

**后果示例**：因把 11,838 当正文，我得出"该刊无硬上限、蓝图零改动可投"的结论；实际官方 Review 上限 **2,000–7,000 词**，稿件须砍 35%。**一个词数口径错误直接颠倒了投稿决策。**

**做法**：
1. 先装 `fontTools`（`pip install fontTools`）——pypdf 解析 CFF Type1 字体需要它，缺失会导致**空格丢失、词数偏低**（症状：提取出 `Received:December12,2025.`）
2. 用 `rfind('\nReferences')` 切分 body / refs（用 `rfind` 而非 `find`，正文中可能出现 "References" 一词）
3. 再剥离摘要与图注；图注正则常漏多行图注，**结果应报告为区间而非单值**
4. **参考文献条目数不要用 PDF 提取**（方括号会丢失导致计数失效）→ 查官方 DOI 页或 Google Scholar
5. 确认目标刊字数口径：是否含 abstract / methods / figure legends / tables（各刊不同，不可套用）


### Step 2：竞品与先例扫描（**最容易被跳过，却最能推翻结论**）

在比任何分区/IF 之前，先做两项检索。这一步的结论可以直接颠倒排序。

**2A. 同题材竞品扫描 —— 全库检索，不限定刊物**

用主题关键词（非刊名）检索近 12–18 个月已发表的同题材论文，**包括预印本与新创刊物**。要查的是"谁已经把我要说的话说了"：

| 检索维度 | 为什么要查 |
|---|---|
| 同题材**综述/立场文** | 直接决定差异化还剩多少；须逐条比对框架、主张、结论 |
| 同题材**benchmark 研究文** | 它会**取代综述的部分论证职能**——有原始数据背书后，你的综述应引为证据而非重述 |
| **新创刊物**（Vol 1 的 OA 刊、Trends Open 类） | 门槛低、审稿快，常是竞品最先落地的地方，容易漏检 |

⚠️ **实测教训**：AIVC 综述选刊做了三轮评估，前两轮都漏掉了竞品。第三轮才查出**三篇同题材论文全在 2026 年内**（两篇落在同一本刊、一篇落在 Cell Press 新创 OA 刊），其中一篇摘要**一次性打包了本文四条核心主张**。这直接导致：①头号原创论点作废；②原首选刊因"半年内已刊两篇同题材"被降级。

**2B. 目标刊先例扫描 —— 反过来查"这本刊收不收我这类稿"**

对每个候选刊，检索它**近三年发过的同类文章**，确认三件事：

1. **体量先例**：同类文章实际多长？（官方上限常有弹性，但弹性上限要用实测先例校准，不能凭上限推断）
2. **形态先例**：它收不收"纯综述 + 基准/指标指南 + 无自研软件"？很多方法类刊物名义上有 Review 栏目，实际只收带工具的
3. **拥挤度**：同题材在该刊的密度。**同一本刊半年内发过两篇同题材 → 短期再收第三篇的概率很低**，即使 scope 契合度最高也应降级

💡 **拥挤度是常被忽略的正向指标**：一本 scope 稍窄但**零同题材占用**的刊，命中率可能高于 scope 完美但已发两篇的刊。

### Step 3：四类数据，四个指定权威源

| 数据类型 | 必须查的源 | 交叉验证 |
|---|---|---|
| **体例上限**（词数/引用/图表） | 各刊**官方** content-types 或 submission-guidelines 页 | 逐刊单独查，**不可套用同家族其他刊** |
| **IF / 中科院分区** | 官方 + 科研通(ablesci)、学术之家(xuehuo)、bioguider | **必须同时记录"新锐分区"与"传统升级版"两套** |
| **CCF 等级** | **ccf.org.cn 官网 PDF 正式版**，逐方向完整列表 | ⚠️ **官网网页版可能滞后于最新目录**——须下载 PDF 核对版本年份；不可凭记忆 |
| **约稿政策** | 官方页面原文，**直接引用原句** | 注意"commissioned""do not encourage uncommissioned"等措辞 |
| **提案通道** | 同上，找"prospective authors should first send…"类表述 | **有低成本提案通道的刊应优先**——可用一页摘要试错，不必先写完全稿 |

### Step 4：算篇幅保留率

`保留率 = 目标刊综述字数上限 / 本文词数`

保留率 <60% 通常意味着**论证密度被破坏**——若稿件的差异化建立在证据密度上（如逐模型审计、定量证据链、检查清单），压缩后会退化成又一篇同质立场文。此时应向用户明示这个代价，而非默默推荐。

### Step 5：按"改动性质"排序，不只按分区高低

| 改动性质 | 含义 | 排序权重 |
|---|---|---|
| **零改动** | 装得下，直接投 | 最高 |
| **删减** | 压篇幅，立场与内容不变，删掉部分可另发 | 高（可逆） |
| **改立场** | 须重构叙事主线（如"评测优先"→"临床转化优先"） | 低（**伤筋动骨，可能改变论文灵魂**） |

⚠️ 分区更高的刊若要求"改立场"，实际劣于分区稍低但"零改动/仅删减"的刊。**必须把这一层判断显式写给用户。**

### Step 6：把"速度"与"试错成本"作为硬指标

- 查"**投稿至接受**"而非仅"首次决定"——两者可差数月（实测有刊首次决定 11 天、接受却要 274 天）
- 在竞品密集发表时，**周期可能比分区更重要**
- **优先有低成本探路通道的刊**：能先用一页摘要试的，就不要先写完全稿。反之，"不接受 presubmission inquiry、只能盲投完整稿"是重大减分项

## 输出格式

三档梯队表，每行含：期刊 / IF / 中科院（新锐·传统双标）/ CCF / 综述体例上限 / 投稿通道 / 命中率。
另附：综合推荐排序（带改动性质列）、**明确排除清单（附理由）**、投稿前动作清单。

## 必须写入交付物的五个提醒

1. **竞品与拥挤度**：列出已查到的同题材论文（载体+时间+抢占了什么），并标注每个候选刊的**同题材占用数**；对用户稿件的差异化主张逐条判定"仍成立 / 被抢先须降级 / 已作废"
2. **分区口径**：哪些刊在"新锐分区"升档但"传统升级版"未升 → 提示用户确认单位采用哪套
3. **约稿门槛**：Nature 系综述普遍要求作者是"recognized experts" → 博士后/学生独立署名可能在初筛被拒，**这与稿件质量无关**；建议先确认资深合作者署名意愿
4. **利益相关披露**：若稿件含企业自评数据或竞赛主办方自研模型，列出须披露对象
5. **"作者自报"标注**：竞品模型的性能数字若来自原论文自述而非独立复现，须标注

## Common Mistakes（均为真实踩过的坑）

| 错误 | 纠正 |
|---|---|
| **同家族刊物规格互相套用** | 曾把 Nature Sustainability 的 Perspective 规格（5,000词/60引用/6图表）当成 Nature Computational Science 的，实际是 **≤4,000词/100引用**。每刊单独查官方页 |
| **用估计值填 IF/分区栏** | 曾以 `~11–14` 填 NatComputSci 的 IF，实际 **20.3**——该错误足以让它从推荐第3位升到第2位。**查不到就写"未核实"，绝不填估计值** |
| **凭记忆断 CCF 等级** | 曾假设 Briefings in Bioinformatics 无 CCF 等级，实为 **CCF-B**（交叉/综合/新兴方向）；曾以为 ACM Computing Surveys 是 CCF-A，实际**不在 CCF 目录**（它是中科院1区Top/IF 30.4，但 CCF 无等级） |
| **默认"CCF-A 总有一本能投"** | 交叉领域常无可用 CCF-A：AI 方向 A 类仅 AI/TPAMI/IJCV/JMLR（JMLR 不收 unsolicited 综述），理论方向是纯数学，交叉方向仅 JACM/Proc.IEEE/SCIS。若用户考核硬性要 CCF-A，须如实告知并给出改写代价 |
| **只看分区不看 scope 排除条款** | Trends in Biotechnology 官方明确不收 systematic/meta-analysis；NRMP 明确不发 systematic review。撞条款直接排除，不必再比分区 |
| **把"能压缩"当成"该压缩"** | 压缩会破坏论证密度。若稿件差异化依赖密度，须把这个代价摆给用户 |
| **只查首次决定时间** | 首次决定快 ≠ 接受快。曾漏掉 Cell Systems 投稿至接受 **274 天**这一决定性劣势 |
| **把 PDF 总词数当正文词数** | 见 Step 1。参考文献占 11%–41%，此错误曾直接颠倒推荐结论 |
| **用一篇"先例"证明体量可行，却不查官方上限** | 先例的实际篇幅可能正好卡在上限（Jiang ~7,000 词 vs BriefBioinform 上限 7,000）。**先例只能证明"该刊接受这个题材"，不能证明"该刊接受这个长度"——长度必须查官方体例** |
| **推荐时只看体量匹配，忽略 scope 文字** | BriefBioinform 官方 Aims 逐句点名要 benchmarking / bottleneck / reproducibility / independent evaluation，与稿件核心章节一一对应——**scope 契合比体量匹配更能决定命中率**。务必读官方 Aims & Scope 全文，而不是只看影响因子和分区 |
| **不做竞品扫描就排序** | 曾连做三轮选刊评估都未检索同题材已发表论文，第三轮才查出三篇竞品（两篇挤在同一本刊）。**这直接推翻了首选刊，并作废了头号原创论点。竞品扫描必须是 Step 2，早于任何分区比较** |
| **忽略"拥挤度"这个正向指标** | 曾把 scope 契合最强、且半年内已刊两篇同题材的刊列为首选。反之，一本 scope 稍窄但**零同题材占用**的刊命中率更高。**同刊同题材密度高 = 降级理由，即使它各项指标都漂亮** |
| **把 CCF 官网网页版当最新版** | ccf.org.cn 的分类页面可能滞后于最新目录（第七版 2026-03-31 发布后，网页版一度仍显示第六版内容）。**判别法：找一个已知变动的条目做版本探针**（如 TMM 在第六版为 B 类、第七版升 A 类——网页版若显示 TMM 在 B 类即为旧版）。**结论性判断须下载官方 PDF 逐字核对** |
| **漏掉"低成本提案通道"** | 曾把某刊标为"以约稿为主"就下调其排名，却漏掉官方同句写着"prospective authors should first send a **one-page abstract or summary**"——即只须一页摘要即可探路。**约稿制 + 有提案通道 ≠ 无门可入；反之"只能盲投完整稿"才是重大减分项** |

## Red Flags — 出现即停下核实

- 表格里出现 `~`、`约`、`预计` 修饰的 IF 或分区 → **是估计值，必须查证或标注未核实**
- 正在用"Nature 系一般是……"的句式推断某刊规格 → 停，去查该刊官方页
- 准备说"这本刊是 CCF-X" → 停，**下载 ccf.org.cn 官方 PDF 核对版本年份**，别信网页缓存
- 推荐排序只按 IF/分区递减 → 停，检查是否漏掉"改动性质"与"接受周期"两维
- **还没检索过同题材已发表论文就在排刊** → 停，先做 Step 2 竞品扫描（含预印本与新创 OA 刊）
- **候选刊里有一本"scope 完美契合"却没查它近期发过几篇同题材** → 停，查拥挤度；同刊半年内两篇同题材 = 降级
- 把某刊判为"以约稿为主"就排除 → 停，重读官方原句，确认有无"prospective authors should first send…"这类提案通道
- 用 PDF 提取的词数直接对比官方字数上限 → 停，先剥离参考文献/摘要/图注（见 Step 1）
