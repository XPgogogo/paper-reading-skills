# 文献综合分析

## 定位

把多篇论文的分散证据转化为研究判断，始终回答三个问题：

- Q1：研究什么——输入、输出、核心矛盾与任务边界是什么？
- Q2：研究到哪里了——路线如何演进，共识、分歧与瓶颈是什么？
- Q3：对研究决策有什么用——哪些方向值得做，如何验证，风险是什么？

核心原则：**先判定证据可比性，再做综合；先证明问题存在，再讨论解决方案。**

## 边界与协作

- 单篇速读、精读、批判、翻译或作者原图提取 → 使用 `paper-reading`。
- 原始 PDF 整文件夹批量精读、20–100+ 篇笔记生产 → 使用 `batch-paper-reading`；本技能可消费其已核验报告做综合，不重复执行批量阅读。
- 英文 Related Work 正式写作、润色或 LaTeX 化 → 使用 `academic-paper-writing`。
- 获取论文 PDF → 使用 `paper-pdf-download`。
- 只要摘要或简单问答 → 直接回答，不强制生成完整报告。

默认在对话中交付。仅在用户要求落盘时创建报告；源 PDF 与文献库保持只读，不移动、重命名或删除源文件。

## 第零步：确定研究上下文与证据范围

提取 `MY_CONTEXT = {研究问题, 所处阶段, 数据类型, 期望输出}`。仅追问会改变分析方向或研究建议的缺失信息，一轮完成；用户要求直接做时，记录假设后继续。

为每篇文献登记：

`论文 / 团队 / 年份 / 证据范围（全文、摘要、题录）/ 数据集 / 预处理 / 划分 / 任务 / 指标`

遵守证据降级：

- 只有题录或摘要时，在报告开头标注「仅基于摘要或题录，结论为低可信度」。
- 全文确实没有的信息写「论文未报告」；摘要没有的信息写「摘要未提供，待全文核查」，不得写成「论文未报告」。
- 不把摘要中的性能声称当作独立复现或已验证事实。

## 工作流

### 1. 建立内部证据记录

按论文提取问题、技术路线、实验条件、baseline、metrics、关键差值、消融、局限与证据位置。该记录用于分析，**不替代「论文阅读」的固定笔记，也不默认输出完整 Paper Card**。

优先记录相对同实验 baseline 的变化，而非只抄最高值；区分作者自述局限与综合推断局限。

### 2. 按路线组织并建立演进链

按问题、方法假设或技术路线聚类，不按论文顺序或年份流水账。每条路线说明：核心思想、代表论文、解决了什么前代缺陷、引入了什么新问题、仍未解决什么。

演进链采用因果形式：

`问题 → 方法路线 → 暴露缺陷 → 后续路线为何出现 → 已解决部分 → 新瓶颈`

### 3. 制作可比性矩阵

3 篇及以上默认制作矩阵，至少包含：论文、问题、路线、数据与划分、baseline、metrics、关键结果、局限、证据位置、可比性。

- 仅在数据、预处理、划分、任务、指标与实验预算足以对齐时直接比较数值。
- 使用不同数据集，或同数据集但划分、预处理不同，不直接排名。
- 不可比时写「不可直接比较」，同时说明可比较的同实验结果或复现结果。

### 4. 判定共识、分歧与成熟度

**共识硬门槛：**至少 2 个相互独立团队的直接证据。共同作者、同团队延续工作不算完全独立；单篇综述只能形成「候选共识（单源综述）」，不能单独证明领域共识。

每条共识记录：内容、独立支持来源、是否跨数据或条件重复、可信度（高/中/低）。证据不足时写「候选共识」或「尚无共识」。

每条分歧记录：观点 A/B、各自实验条件、可能原因、目前有无定论、判别实验。优先排查数据规模、分布、预处理、划分、指标、随机种子、泄漏与 baseline 公平性。

成熟度按需判为：成熟 / 竞争中 / 开放 / 长期难题 / 证据不足无法判定。没有独立复现、公开评估与真实或外部验证，不因单一高指标判为成熟。

### 5. 审查 Research Gap

Real Gap 必须是有证据的**未解决问题**，不是方法组合。每项至少写明：

`现有研究 / 未解决问题 / 证据论文与位置 / 独立证据 / 为何仍未解决 / 价值 / 难度 / 所需数据 / 验证方式`

执行分流：

- 证据充分且能说明未解决性 → `Real Gap`。
- 只有摘要或线索，尚未核实全文 → `候选 Gap`，列出核查动作。
- 仅因「没人用 A 做 B」「没人组合 A+B」「可以换一个模型」→ `Fake Gap`，不推荐，除非能证明现有问题与该方法特有能力之间的对应关系。

**区分两类验证：**现有文献证据用于验证 Gap 是否成立；新实验用于验证解决方案是否有效。组合方法取得提升，只能支持解决方案假设，不能反向证明 Real Gap。

### 6. 给出个性化研究建议

所有建议回指 `MY_CONTEXT`，避免「值得借鉴」等空话。按需覆盖：

- 可作为 baseline 的方法及选择梯度；
- 指标组合及选择原因；
- 主实验、消融、参数敏感性、鲁棒性、泛化、外部验证、复杂度与案例分析；
- 数据准备、划分、泄漏与公平比较风险；
- 候选研究问题、可验证假设、预期贡献与失败条件。

需要详细清单时读取 `references/research-design-checklist.md`。提供选项与权衡，不替用户拍板研究方向。

## 输出模式

- **快速版**：证据范围 + 路线与瓶颈 + 候选共识/分歧 + Gap + 下一步。
- **完整综合报告**：读取 `references/synthesis-template.md`，按模板组织。
- **实验或开题论证**：读取 `references/research-design-checklist.md`，输出研究问题、假设、baseline、metrics、实验、贡献与风险。
- **用户指定结构**：以用户结构为准，不强制 11 章，不生成空章节。

## 证据标签与铁律

重要判断逐条标注：

- `【论文事实】`：论文明确报告的方法、数据或结果，附作者年份及页码/章节（可得时）。
- `【作者观点】`：作者对意义、优势或机制的解释和声称。
- `【综合判断】`：基于多篇证据的综合，列出支持来源。
- `【研究假设】`：尚未验证的组合、机制或研究方向。

1. 禁止编造论文、作者、DOI、样本量、数据划分、指标、数值或消融结果。
2. 引用格式跟随用户；无指定时用 `(Author et al., Year)`。重要结论必须可追溯。
3. 不把单源综述称为已证实共识，不把同团队系列工作当成独立复现。
4. 不跨实验条件直接排名，不忽略年份、baseline 公平性与评估设置。
5. 不把方法组合写成 Gap，不把方案有效写成 Gap 得到证明。
6. 默认中文，模型、数据集与指标名保留英文；术语首次给出中英文，后文保持一致。
7. 仅输出用户需要的深度，不因安装本技能而强制生成长报告。

## 常见错误

| 错误 | 纠正 |
|---|---|
| 一篇综述指出问题，就写成领域共识 | 降为候选共识，寻找第二个独立来源 |
| 摘要没写样本量，就写论文未报告 | 写摘要未提供，待全文核查 |
| 把 A+B 作为 Real Gap | 先找未解决问题；A+B 只作为研究假设 |
| 组合方法提升后声称 Gap 被证明 | 区分 Gap 证据与方案验证 |
| 把不同划分下的数值排成榜单 | 标为不可直接比较，寻找同协议复现 |
| 对 30+ 原始 PDF 逐篇生成 Paper Card | 先调用批量阅读流程，再做综合 |
| 每次固定输出完整 11 章 | 按任务选节，省略空章节 |

## 交付前自检

- 是否说清证据范围与不可比之处？
- 3 篇及以上是否有路线和矩阵？
- 每条共识是否满足独立团队门槛？
- 每条 Gap 是否有问题证据、未解决性说明与验证方式？
- 是否把方案假设与 Gap 明确分开？
- 个性化建议是否回指研究上下文并给出下一步？
