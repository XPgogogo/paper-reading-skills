# Research Gap 与实验设计核查清单

按需使用本清单，不要求所有研究都机械完成全部实验。

## 一、Gap 质量门

逐项回答，无法用证据回答时降级为「候选 Gap」：

- [ ] 是否描述了一个未解决问题，而不是一种方法组合？
- [ ] 是否能指出论文、章节或实验作为问题证据？
- [ ] 是否有独立团队证据，或明确承认为单源线索？
- [ ] 是否说明现有方法为何没有稳定解决？
- [ ] 是否排除「没人用 A 做 B」「换个模型」「同数据同指标只做拼接」？
- [ ] 是否说明科学或应用价值、所需数据与验证方式？
- [ ] 是否区分 Gap 成立证据与解决方案有效证据？

### Real Gap

问题证据、未解决性和验证路径均较明确。只有摘要证据时通常先标「候选 Real Gap，待全文核查」。

### Fake Gap

仅以方法或场景的新颖组合为理由，无法指出待解决的特有缺陷。可保留为研究假设，但不作为开题的核心缺口。

## 二、从 Gap 到研究假设

使用以下链条，缺一环就标出：

`文献证据 → 未解决问题 → 可检验研究问题 → 研究假设 → 方法机制 → 判别实验`

- Gap 回答「什么问题仍存在」。
- 假设回答「什么机制可能解决它」。
- 实验回答「该机制是否有效、何时失效」。
- 不用方案实验的事后成功反向替代 Gap 的文献证据。

## 三、Baseline 选择

按任务实际选择有代表性的梯度，不为凑数量全堆：

1. 简单或传统方法：提供最低可超越基线。
2. 经典深度方法：检验复杂模型是否必要。
3. 当前主流方法：保证与常用方案比较。
4. 强 SOTA：选择问题、数据和评估设置真正可比者。
5. 消融基线：逐一移除核心模块，识别贡献来源。

每个 baseline 记录选择理由、代码或模型版本、预训练来源、调参预算及是否公平复现。

## 四、Metrics 选择

- 从任务目标与失败成本推导指标，不默认只看 Accuracy。
- 解释主指标为何衡量核心目标，补充指标为何能暴露另一类失败。
- 同时考虑数据不平衡、校准、排序、生成质量、效率或外部有效性等任务相关维度。
- 保持指标方向、计算方式、平均方式和置信区间口径一致。
- 不编造领域标准指标；不确定时先核实相关论文与基准。

## 五、公平比较协议

在比较数值前逐项核对：

- [ ] 数据版本、样本范围与预处理一致或差异已明确。
- [ ] 训练、验证、测试划分一致，并检查实体、时间、患者、细胞或扰动等可能的泄漏。
- [ ] 主干、预训练信息、训练预算和调参机会公平。
- [ ] 使用相同指标实现与统计口径。
- [ ] 多种子报告均值、方差或置信区间；必要时做显著性检验。
- [ ] 不同协议结果只作背景，不进入同一数值排行榜。

## 六、实验组合

按研究假设选择最小充分组合：

- **主实验**：验证核心问题与主要对比。
- **消融**：验证每个关键模块或设计选择的贡献。
- **参数敏感性**：检验结论是否依赖单一设置。
- **鲁棒性**：噪声、缺失、分布偏移或扰动下的稳定性。
- **泛化**：跨数据集、跨域、跨任务或未见条件。
- **外部验证**：独立来源数据或独立团队结果。
- **效率**：参数量、训练/推理时间、显存或计算成本。
- **案例分析**：成功与失败案例都要解释，不只展示有利样例。

每项实验注明：对应假设、预期观察、支持标准和失败后的解释。

## 七、证据升级路径

`题录/摘要线索 → 全文核查 → 同协议复现 → 跨数据验证 → 独立或外部验证`

低层证据可以形成候选方向，不能冒充高层结论。优先补做能改变研究决策的核查，而非无差别增加实验数量。

## 八、开题或选题输出

用户明确要求开题论证时，按需输出：

- 研究背景与问题定义；
- Gap 证据与差异化定位；
- RQ1–RQ3 与对应假设；
- 方法 Pipeline 及关键机制；
- Baseline、Metrics 与公平比较协议；
- 主实验、消融、泛化及外部验证；
- 预期贡献（数据/方法/理论/任务/实验/系统）；
- 数据与算力需求、时间风险、失败条件和备选方向。
